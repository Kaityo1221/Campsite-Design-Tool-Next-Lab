# Campsite Design Tool Next Lab

Future development laboratory for the next generation of Campsite Design Tool.

## Scope

- CREATIVE MODE
- PROJECT
- ADV
- Other future experimental features

## Important

This repository is a development laboratory for future Campsite Design Tool features.
Do not deploy or merge this repository directly into the production repository.
Production changes must be reviewed and selectively ported to `Kaityo1221/Campsite-Design-Tool-JP` only after approval.

## Visibility

This repository is intentionally public so development previews can be opened directly from mobile browsers.
Preview pages must use `noindex, nofollow` and should not be treated as production pages.
