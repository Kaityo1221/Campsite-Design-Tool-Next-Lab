## 安全運用ルール

1. 1回の改修は1機能ずつ。複数機能の共通化を先にしない。
2. main はユーザーが明示的に「マージして」と言うまで触らない。
3. 入口初期化コード `entryFile.onchange` / `start.onclick` / 左右利き切替 / `beginEditor()` は不用意に触らない。
4. 変更後は必ず JavaScript 構文チェックを通す。
5. iPhone Safari では毎回、ファイル選択 → 左右利き → CREATIVE MODE開始の入口スモークテストを先に行う。
6. 入口確認後、そのコミットで変更した機能だけを確認する。
7. 失敗時は推測修正を重ねず、直前の成功地点へ戻す。
8. テストURLは commit SHA 直指定を優先する。
9. 本番リポジトリ `Campsite-Design-Tool-JP` は明示指示なしで更新しない。

## 次回開発バッチ

誤操作防止を最優先する。POIの位置移動は現行の「POIを選択 → 位置を調整 → 地図を動かして中央十字へ合わせる → この位置に確定」を維持し、POIの直接ドラッグ移動には変更しない。

1. 保存時のファイル名変更
   - 保存操作後にファイル名入力モーダルを表示する。
   - 現在の名前を初期値として入れ、変更したいユーザーだけ編集できるようにする。
   - `.kmz` は固定扱いとして入力対象から外す。
   - 未入力時は従来のファイル名へフォールバックする。
   - A案 / B案など複数パターンを区別して保存できるようにする。

2. オープニング画面のリリースノート
   - 次回リリースからオープニング画面に WHAT'S NEW / LAB UPDATE 相当の更新カードを追加する。
   - 新バージョン初回は認識しやすくし、2回目以降は操作を邪魔しない表示にする。

3. Creative Mode入口を CSV / KMZ に整理
   - 正式サポート対象は `CSV` と `KMZ` のみ。KMLは通常UIおよび正式サポート対象から外す。
   - 表示は「CSV / KMZを選択」。案内文は「編集するCSVまたはKMZを選択してください。」とする。
   - CSVは本体同様に複数選択を許可し、複数CSVをまとめて読み込む。
   - KMZは1ファイルのみ。CSVとKMZの混在選択は不可とする。
   - CSVの列解釈は本体 `js/util.js` の `parseCSV` と同等の互換性を維持する。緯度 / 経度、name / title、gameEntity / type 等の主要列名を許容する。
   - 複数CSVは読み込み時に統合し、GUIDまたは座標で重複を除外する方向とする。

4. My Maps上限ガード
   - Google My Mapsへの持ち出しを前提に、5MB上限を超えないよう選択時と保存前にチェックする。
   - 4.5MB以上は黄色警告、5MB超は保存 / 読み込みを止める。
   - My Mapsの10レイヤー上限を監視する。
   - 現行Creative Modeの出力は固定レイヤー構成を優先し、複数CSVをそのままCSV数分のレイヤーへ増やさない。
   - 出力見込みレイヤー数が10を超える場合は保存を止め、レイヤー削減を案内する。
   - サイズは入力ファイル合計だけではなく、最終KMZ Blob生成後にも再確認する。

5. 誤ファイル形式の案内強化
   - `.mht` / `.mhtml` / `.eml` など、Google My MapsのWebページ保存ファイルを識別できる場合は専用メッセージを出す。
   - 「読み込めません」だけで終わらせず、「Google My MapsからKMZを書き出して読み込んでください」と案内する。
   - KML選択時も「CSVまたはKMZを選択してください」と明示する。

6. ダブルタップズーム
   - スマホで地図の空白部分をダブルタップした場合のみズームインする。
   - POI、線、ポリゴン、ボタンなど操作対象上では発動させない。
   - 編集操作やスクロールとの競合を避け、「触っただけでは編集されない」設計を維持する。

## My Maps持ち出し前提

- インポート可能サイズ: 5MBを上限として設計する。
- レイヤー数: 10レイヤーを上限として設計する。
- 余裕を持たせるため4.5MBから警告を出す。
- Creative Mode内で正常に扱えても、My Mapsへ持ち出せないデータは完成扱いにしない。

## 開発順序

安全運用ルールに従い、一括実装せず1機能ずつコミット・実機確認して積み上げる。CSV複数読み込みとMy Maps上限ガードは入口処理を変更するため、既存の①〜⑤レビュー成功地点とは別に再スモークテストする。mainへのマージは明示指示があるまで行わない。
